# 📁 config/githooks

Папка `config/githooks` хранит локальные git hooks проекта.
Они подключаются через настройку `core.hooksPath`, поэтому не требуют Husky, Lefthook или дополнительных npm-пакетов.

## Установка

Hooks устанавливаются автоматически после установки зависимостей:

```sh
npm install
```

За это отвечает скрипт `postinstall` в `package.json`, который запускает:

```sh
npm run hooks:install
```

Если нужно переустановить hooks вручную, можно выполнить эту команду отдельно.
Она выставит `core.hooksPath` на `config/githooks` и сделает `pre-commit` исполняемым.

## Pre-commit

Перед коммитом hook проверяет staged-файлы и запускает:

```sh
npm run build
```

Проверка запускается только если в индексе есть изменения проекта.
Если шаблон используется как отдельный репозиторий, учитываются любые staged-изменения.
Если фронтенд лежит подпапкой внутри общего репозитория, hook вычисляет фактический путь проекта и реагирует только на
файлы внутри этой папки.

Например, hook корректно работает для разных вариантов вложенности:

```txt
client-app/
apps/client-app/
frontend/projects/site/
```

## Ограничение

В одном git-репозитории может быть только один `core.hooksPath`.
Если в монорепозитории несколько фронтенд-проектов со своими hooks, последний запущенный `npm install` перезапишет
локальную настройку hooksPath.
